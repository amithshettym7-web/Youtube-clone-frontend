# YouTube Clone 🎥

A simple **YouTube Clone** created using **HTML and CSS**.
This project was built to practice frontend development, page layout, styling, and responsive design.

## 🚀 Technologies Used

* **HTML5** – Used to create the structure of the website.
* **CSS3** – Used for styling, layout, colors, spacing, and responsiveness.

## ✨ Features

* YouTube-inspired homepage
* Navigation sidebar
* Search bar UI
* Video thumbnail cards
* Video titles and channel information
* Responsive layout
* Clean and simple user interface

## 🖥️ How to Run

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional libraries or frameworks are required.
